# Support

Mantra is pre-1.0 and maintained on a best-effort basis. No commercial support or domain-compliance
service is offered.

Start with the [README](README.md), [DSL reference](docs/dsl-reference.md), application READMEs under
`apps/` and the [workbench contract](docs/workbench/contract.md). The [roadmap](docs/roadmap.md)
records scope and planned capabilities.

Report ordinary bugs and feature requests through [GitHub issues](https://github.com/6234456/mantra/issues).
Include:

- Mantra commit and `normein-build.lock` contents;
- Java version, Node.js version for frontend issues, and operating system;
- The exact command or workbench action;
- Minimal fictional schema, case and layout files, and expected versus actual behavior;
- For calculation discrepancies, an independent recomputation or source reference;
- For XLSX discrepancies, the export coverage report and affected cells.

Remove confidential data and credentials. Follow [SECURITY.md](SECURITY.md) for private vulnerability
reports. The applications demonstrate engine capabilities and are not a source of tax or accounting advice.
