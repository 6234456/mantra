1/3 Weighting based on useful life [North]
    Formula: (if weight-by-life (decimal/divide remaining-life (dim/min all.remaining-life) 4) 1)
    Working: if(true; decimal/divide(6; dim/min({:A 6; :B 12; :C 18}); 4); 1) = 1
1/3 Weighting based on useful life [Central]
    Formula: (if weight-by-life (decimal/divide remaining-life (dim/min all.remaining-life) 4) 1)
    Working: if(true; decimal/divide(12; dim/min({:A 6; :B 12; :C 18}); 4); 1) = 2
1/3 Weighting based on useful life [South]
    Formula: (if weight-by-life (decimal/divide remaining-life (dim/min all.remaining-life) 4) 1)
    Working: if(true; decimal/divide(18; dim/min({:A 6; :B 12; :C 18}); 4); 1) = 3
1/4 Carrying amount after weighting [North]
    Formula: (* carrying-amount weighting)
    Working: 120 × 1 = 120
1/4 Carrying amount after weighting [Central]
    Formula: (* carrying-amount weighting)
    Working: 180 × 2 = 360
1/4 Carrying amount after weighting [South]
    Formula: (* carrying-amount weighting)
    Working: 260 × 3 = 780
1/5 Pro-rata allocation factor [North]
    Formula: (decimal/divide weighted-amount (dim/sum all.weighted-amount) 6)
    Working: decimal/divide(120; dim/sum({:A 120; :B 360; :C 780}); 6) = 9.5 %
1/5 Pro-rata allocation factor [Central]
    Formula: (decimal/divide weighted-amount (dim/sum all.weighted-amount) 6)
    Working: decimal/divide(360; dim/sum({:A 120; :B 360; :C 780}); 6) = 28.6 %
1/5 Pro-rata allocation factor [South]
    Formula: (decimal/divide weighted-amount (dim/sum all.weighted-amount) 6)
    Working: decimal/divide(780; dim/sum({:A 120; :B 360; :C 780}); 6) = 61.9 %
1/6 Allocated shared facilities [North]
    Formula: (alloc/pro-rata allocable-corporate all.weighted-amount rounding)
    Working: alloc/pro-rata(211; {:A 120; :B 360; :C 780}; 0) = 20
1/6 Allocated shared facilities [Central]
    Formula: (alloc/pro-rata allocable-corporate all.weighted-amount rounding)
    Working: alloc/pro-rata(211; {:A 120; :B 360; :C 780}; 0) = 60
1/6 Allocated shared facilities [South]
    Formula: (alloc/pro-rata allocable-corporate all.weighted-amount rounding)
    Working: alloc/pro-rata(211; {:A 120; :B 360; :C 780}; 0) = 131
1/7 Carrying amount after allocation [North]

    Working: 120 + 20 = 140
1/7 Carrying amount after allocation [Central]
    Formula: carrying-amount + corporate-share
    Working: 180 + 60 = 240
1/7 Carrying amount after allocation [South]

    Working: 260 + 131 = 391
2/2 Recoverable amount (higher of value in use and FVLCD) [North]
    Formula: max(cgu.value-in-use; cgu.fvlcd)
    Working: max(Value in use 180; Fair value less costs of disposal n/a) → Value in use = 180
2/2 Recoverable amount (higher of value in use and FVLCD) [Central]
    Formula: max(cgu.value-in-use; cgu.fvlcd)
    Working: max(Value in use 210; Fair value less costs of disposal n/a) → Value in use = 210
2/2 Recoverable amount (higher of value in use and FVLCD) [South]
    Formula: max(cgu.value-in-use; cgu.fvlcd)
    Working: max(Value in use 300; Fair value less costs of disposal n/a) → Value in use = 300
2/3 Impairment loss [North]
    Formula: (max 0 (- tested-amount recoverable-amount))
    Working: max(0; 140 − 180) = –
2/3 Impairment loss [Central]
    Formula: (max 0 (- tested-amount recoverable-amount))
    Working: max(0; 240 − 210) = 30
2/3 Impairment loss [South]
    Formula: (max 0 (- tested-amount recoverable-amount))
    Working: max(0; 391 − 300) = 91

    Working: min(0; or(nil; 0)) = –

    Working: min(30; or(nil; 0)) = –
3/1 To goodwill [South]

3/2 Loss assigned to shared facilities [North]
    Formula: (get (alloc/pro-rata (- impairment-loss loss-to-goodwill) {:corporate corporate-share :own (- carrying-amount (or cgu.goodwill 0))} rounding) :corporate)
    Working: get(alloc/pro-rata(0 − 0; {:corporate 20; :own 120 − or(nil; 0)}; 0); :corporate) = –
3/2 Loss assigned to shared facilities [Central]
    Formula: (get (alloc/pro-rata (- impairment-loss loss-to-goodwill) {:corporate corporate-share :own (- carrying-amount (or cgu.goodwill 0))} rounding) :corporate)
    Working: get(alloc/pro-rata(30 − 0; {:corporate 60; :own 180 − or(nil; 0)}; 0); :corporate) = 8
3/2 Loss assigned to shared facilities [South]
    Formula: (get (alloc/pro-rata (- impairment-loss loss-to-goodwill) {:corporate corporate-share :own (- carrying-amount (or cgu.goodwill 0))} rounding) :corporate)
    Working: get(alloc/pro-rata(91 − 0; {:corporate 131; :own 260 − or(nil; 0)}; 0); :corporate) = 30
