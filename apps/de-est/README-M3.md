# Income-tax carryforward and trade-tax credit demonstrations

**Uncompiled M3 application draft.** These project-authored fictional cases are for engine demonstration only. No engine, browser, rendering or XLSX acceptance has been run for this draft. This document does not claim tax-software suitability.

The original scheme de.est/2025@2025.2 keeps its computational files unchanged. The two copied legacy cases explicitly select that version. The new versions/2024.1 loss ledger has identity de.est-loss/2024@2024.1; versions/2025.3 has identity de.est/2025@2025.3. Layout and parameter IDs are unique. All application calculations use ordinary public schema primitives; the host binds exact schema versions generically.

The 2024 closing loss is a stock transferred once to the 2025 opening input. Supported cases waive carryback. Eligible new loss is a supplied fact after within-year offsets. The selected §10d limit uses a EUR 1,000,000 allowance (EUR 2,000,000 in the focused joint amount test) plus 70% of positive income above that allowance. The joint fixture tests only that amount; it does not claim spouse attribution or a complete joint tax assessment.

Five linked consumers cover the original source, revised source, exhausted carryforward, explicitly provided zero, and a source with a BUSINESS error. Signed invalid source facts remain visible. An inherited source finding must keep validationPassed=false while preserving a technically successful linked amount and its provenance. Nil, missing, inactive or technically failed source values cannot be replaced with zero or stale amounts.

Six further consumers receive scalar Gewerbesteuer assessment and liability values into complete Person A coordinates. gewst-due means the assessed liability for the year, not cash paid. The §35 upper limit is tariff tax times positive trade income divided by all positive income. Negative other income does not reduce that denominator. Zero denominator gives the selected legal limit zero. The complete fixtures use integral final credits; no rounding rule is inferred for the separately frozen fractional-cap example.

The displayed main line still uses actual Staffel totals. Loss deductions reduce income once. §35 reduces income tax once and the selected solidarity-surcharge base accordingly. New selected cases have no children, church tax, partnerships, foreign-source attribution, special loss baskets or other material deductions beyond the single EUR 36 flat amount. Their simplifications are also commented in the schemas. Other legacy ESt simplifications remain visible in the copied fragments.

Primary context: [official §10d for 2024](https://esth.bundesfinanzministerium.de/esth/2024/A-Einkommensteuergesetz/II-Einkommen-2-24b/5-Sonderausgaben-10-10g/Paragraf-10d/inhalt.html), [official §10d for 2025](https://esth.bundesfinanzministerium.de/esth/2025/A-Einkommensteuergesetz/II-Einkommen-2-24b/5-Sonderausgaben-10-10g/Paragraf-10d/inhalt.html), [official §35 for 2025](https://esth.bundesfinanzministerium.de/esth/2025/A-Einkommensteuergesetz/V-Steuerermaessigungen-34c-35c/3-Steuererm.-bei-Eink-aus-Gewerbebetrieb_35/Paragraf-35/paragraf-35.html), [administrative context](https://esth.bundesfinanzministerium.de/esth/2025/B-Anhaenge/Anhang-27b/I/inhalt.html), [historical 2025 tariff](https://amtliche-handbuecher.bundesfinanzministerium.de/esth/2025/A-Einkommensteuergesetz/IV-Tarif-31-34b/Paragraf-32a/inhalt.html), and [historical 2025 solidarity-surcharge provisions](https://lsth.bundesfinanzministerium.de/lsth/2025/B-Anhaenge/Anhang-27/I/inhalt.html). These sources support selected concepts and historical applicability, not the fictional amounts. No official numerical example or substantial statutory passage is copied.

independent/ preserves the original Decimal/Fraction source algorithm, selected fictional JSON facts and immutable references. case-map.json maps source numeric addresses to real schema addresses. A ledger alias keeps the same independently computed amount; gewst-payable@A becomes the new input gewst-due@A. No expected amount comes from an engine, paper or workbook. The five standalone non-linked 2025 loss boundaries additionally have selected tax-chain references generated by exact BigInt rational arithmetic from frozen facts and historical parameters; the Python adapter checks those independently with the original Decimal/Fraction tax function. These new draft references supplement rather than overwrite the original frozen references. The focused joint case deliberately has no final tax reference.
