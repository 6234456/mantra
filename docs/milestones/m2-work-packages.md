## 期间与依赖

```clojure
(dimension year {:periods {:start "2026-01-01" :unit :year :count 5}})
(dimension fiscal-year
  {:periods [{:key :FY2026 :start "2026-07-01" :end "2027-07-01"}
             {:key :FY2027 :start "2027-07-01" :end "2028-07-01"}]})
```

- 期间采用半开区间，`:end` 不属于本期。静态声明顺序就是时间顺序，键唯一、起止有效、相邻
  边界完全相接；不排序补洞。生成支持月、季、年和正整数期数，成员键为 `P1` 至 `Pn`，
  每个边界从原始起点加月份，避免月末逐次累加漂移。
- 当前期间记录提供 `key`、零起 `index`、`start`、`end-exclusive`、`previous-key`；首期前键
  为 nil。`periods.<dimension>.keys` 是声明顺序的键列表。期间轴不能用成员条件或数据过滤删除
  中间期间；适用性属于计算节点。月份和非日历财年属于通用日期语义。
- `(prev closing first-expression)` 引用相同其他坐标的上一期期末，首期只执行显式后备表达式。
  后备表达式延迟求值；上一期真实 nil 保留，不转成零，也不改用首期后备值。全局 `prev` 为宿主
  原语，局部绑定或具名函数同名时保持词法遮蔽。原始源码位置和具名定义来源随 trace 保留。
- 调度任务包含节点和成员坐标。上一期依赖严格向过去，普通当前期自引用、域生成循环及全成员
  映射循环仍拒绝，并报告带期间的路径。条件、输入校验和 spread 依赖沿用 M1 语义，不能为消除
  假环而丢掉实际依赖。每期期末单独计算、可寻址、可 Explain。
- 无审计计算接入 Normein 执行计划/会话的 VALUE_ONLY；审计与 Explain 使用 FULL trace。工作台
  编辑按依赖图失效重算，变更输入、参数、公式或成员域时分别遵守缓存有效性，不能复用旧 trace
  伪装新计算。文档修订和审计过期规则继续有效。

## 汇总与期间层级

数字输入、field、line、total 和 choice 均可声明 `:aggregate {:first year}` 或 `{:last year}`。
未移除期间轴时其他维度求和；移除期间轴时每个剩余坐标组取声明范围的首期或末期，再汇总其他轴。
不寻找“最后非零”或“最后有效”期间。选中边界的有效 nil 传播未定义；没有有效贡献保留现有中性规则。
原 `:sum`、`:none` 与分子/分母比率规则保留。

`CalculationView.reduce(nodeId, fixed)` 返回只读的 `AggregationResult`，值与 ratio/boundary/sum
证据由同一核心归约器生成。固定坐标之外的维度参与汇总，明细有预算、完整结果不截断。纸面、工作台和
XLSX 使用该证据与声明规则，不能各自重新定义存量算法。M1 的比率证据 API 保留兼容入口。

期间 `:parent` 复用原关系模型，按完整区间包含建立月→季→年映射；跨父期间或未被包含的期间拒绝。
原三参数 `dim/rollup(values, parents, key)` 继续求和；五参数形式显式提供 `:first|:last` 和期间顺序，
不通过猜测引用节点暗中改变函数含义。

## 布局、地址与工作簿

```clojure
(table asset-bridge {:style :matrix :row-dimension asset}
  :label (members year) :cross-total)
(table asset-summary {:style :transpose :row-dimension asset}
  :label (node gross-closing) (node accumulated-closing) (node net-closing))
```

- 二维矩阵以行维度分组，项目为组内行、另一维度为列，组内合计遵守度量规则。转置矩阵以成员为行、
  指定节点为列；可用 `:fixed {:year :P3}` 限定切片。布局不改变引擎数值。
- `PaperRow.valueAddresses` 与单元格对齐，明确节点、多维坐标，或汇总固定坐标。工作台延续已有地址格式；
  `aggregate.<node>` 的固定坐标为按方案声明维度排序的 `dimension=member`，包含祖先期间范围。每个可点选数字都有引擎地址。
- 工作台 JSON 升为 `mantra.workbench/3`，汇总证据按 `kind` 区分 ratio/boundary/sum。严格 schema、
  TypeScript、金本及 UI 同步更新；宿主 DSL/库升为 0.3。`mantra.calc@1` 保持原有函数语义。
- XLSX 将 prev 译为上一期对应单元格引用；存量横向合计取边界，流量求和。二维和转置单元格都保留公式。
  日期使用 `EDATE`、`EOMONTH` 等对应函数。生成时审计快照及输入变化后的过期提示继续采用维护者确认行为。
