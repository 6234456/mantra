## 当前切片

承接 [统一源历史](source-history-progress.md)，推进 G-A12 的客户端部分。真实 `/template-preview`
新增浏览器自动副本和独立格式 `mantra.template-preview-recovery/1` 的 JSON 下载／导入。
备份包含根 schema／layout 原文、启用的原始输入和未 Apply 的布局／class 字段；不存计算结果、
旧权限、有效状态或 Undo/Redo。恢复后重新 Inspect／Apply、真实 Preview，不恢复信任状态。

使用步骤与启动入口见 [用户说明](../../site/template-recovery.md)，格式见
[契约 §7.1](../contract.md#71-操作) 与 [schema](../schema/template-recovery.schema.json)。

- workspace／template-sources 增加 canonical root 的不透明 workspaceId。相同规范根路径跨重启稳定，
  不同目录即使完整源内容相同也隔离；不返回路径，不复用会话令牌。
- 自动副本按 origin／workspaceId／case 分槽；读取旧副本后先等用户 Restore／Discard，不让干净初始化
  或另一新草稿覆盖它。延迟写入与 pagehide 刷新使用最新已提交状态，回读成功后才表示最新内容已保护。
- 恢复必须匹配完整图修订、参与源映射、全部根 descriptor 与 baseText。旧基准和损坏记录保留供下载，
  不自动 merge／rebase。显式文件导入可跨 workspace，但须完整源证据仍相同且用户明确 Restore。
- 恢复取消旧候选与保存基准请求、清除结果／诊断／内存历史，标为 Restored · not validated。
  只有当前真实候选技术有效 200 且无未应用字段才解除；运行时失败、业务 finding 仍显示其真实状态。
- 无效输入在没有 Structure 时也按 node ID 显示为可编辑／可移除的未校验覆盖。字段缓冲在无目录或离线
  时保留原始摘要和 Cancel；重新检查前不能 Apply，不能因恢复丢掉 `nine`、空文本、false、0、精确十进制或 `-`。
- JSON 总预算 2 MiB UTF-8／深度 16，拒绝转义同名重复键、未知字段、错误形状、重复身份和伪造证据。
  draft 字符串不套用预览 65536 限制，70k 的无效粘贴仍可在总预算内保存；超预算不截断。
- 存储故障、配额失败、他页修改或不兼容副本均明确表示未保护／暂停；当前草稿仍保留，可下载合法 JSON。
  比较期望原文和读回不是跨标签事务，不承诺并行编辑同步或自动合并。

这不是模板文件 Save、服务端草稿、恢复源历史或发布；G-A7、服务端 G-A12 与 D-A1 保持未完成。
录制原型使用另一格式，不引入其运行时依赖，也没有修改内核、计算原语或依赖版本。
